📥 Nhập TKB vào tài khoản

Dán mã đồng bộ của máy bạn, tải file TKB tổng của trường lên, chọn đúng lớp — dữ liệu sẽ tự đồng bộ về app MinT's Study Space trên máy đó.

1 Mã đồng bộ máy
Mở app chính → Cài đặt → mục "Mã đồng bộ" → bấm Sao chép → dán vào đây. Nếu mã sai hoặc chưa từng tạo, dữ liệu sẽ không vào đúng máy của bạn.
2 Lớp của bạn
Gõ đúng tên lớp như trong file TKB tổng của trường (VD: 10X4). Khi tải file ở bước dưới, app sẽ tự lọc đúng cột của lớp này.
3 File TKB Excel (.xls / .xlsx)
Dùng file TKB tổng của trường (nhiều lớp trong 1 file) — giống file vẫn dùng để nhập trong app chính. Mỗi sheet sẽ tự chọn đúng cột lớp bạn đã gõ ở trên — nếu không khớp, tự chọn tay lại được.
Quét ảnh / file bằng AI Sắp ra mắt
Chụp ảnh TKB rồi để AI tự đọc — đang chờ có API key, làm sau khi phần Excel chạy ổn.
